# AgentPay Web Application

Next.js web dashboard shell for AgentPay: Programmable USDC infrastructure for autonomous agents on the Arc blockchain.

## Technology Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Linting**: ESLint

## Routes

- `/`: Product overview and pipeline introduction.
- `/dashboard`: Operator dashboard shell displaying vault balances, service health, and active agent limits.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run linting
npm run lint
```
